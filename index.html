1. Autonomous WebSocket Lifecycle

Multi-stream support across BTC, ETH, SOL, BNB, XRP, and DOGE. Clean lifecycle handling with socket teardown, exponential backoff, and port-443 fallback.

2. Garbage Collection & Memory Bounds

Historical data array is strictly capped at 15 items using Array.shift(). This enforces an $O(1)$ memory ceiling on the V8 heap, eliminating memory leakage and GC stutter under continuous high-frequency streams.

3. Canvas Optimization Trick

Uses chart.update('none') on every tick. This skips Chart.js's expensive easing animations, preventing CPU core saturation, layout reflows, and dropped frames during rapid bursts of trades.
